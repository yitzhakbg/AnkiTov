Expand description

Top-level OpenAPI aggregation and live serving of the API reference.

Every controller route carries a #[utoipa::path] annotation; this module stitches them into one spec and serves it:

  • GET /api/v1/openapi.json — machine-readable OpenAPI 3.0 spec
  • GET /scalar — interactive Scalar API reference (CDN embed)

The spec is always current: it is generated from the compiled annotations at request time, so it cannot drift from the running server. Registered as public routes in App::after_routes (outside the management JWT gate — docs are meant to be browsable without credentials).
