Management Console — Jev Prompt Translator controller.

Exposes the bidirectional translation between free-form human prompts and TypeSafe System One (Jev) evaluation requests:

  • POST /management/jev/human-to-jev — translates a human prompt into a ready-to-send Jev request body.
  • POST /management/jev/jev-to-human — renders a Jev request body as a readable English summary.
  • POST /management/jev/evaluate — sends a ready Jev request to the TypeSafe endpoint and returns the response.

See crate::services::jev_translator for the implementation.
