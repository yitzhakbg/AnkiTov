Verifies an .apkg file on disk and produces a DeckVerificationReport.

Implementations must be Send + Sync (used from axum handlers).

Verify the package at apkg_path.

Returns Ok(report) with report.ok == false for a verifiably bad package (e.g. corrupt/foreign file) — rejection is a report, not an error. Err is reserved for infrastructure failures (missing file, backend unreachable).
