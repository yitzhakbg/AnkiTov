Produce a unique profile name for the given user, deduping against existing students.

Starts from the name-derived base. If another student already has a row whose username equals the base (i.e. the bare name is taken), append the student’s numeric id as a -<id> suffix so the two never collide. The password (also id) is the true uniqueness key, so even a base-name collision still yields a distinct sync identity; the suffix keeps the name readable and unambiguous in the UI.
