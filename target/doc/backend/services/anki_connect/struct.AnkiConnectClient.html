Struct AnkiConnectClient

pub struct AnkiConnectClient { /* private fields */ }
Expand description

AnkiConnect Direct HTTP client.

Constructed with a port and optional API key. All calls are serialized through a tokio::sync::Mutex (concurrency = 1). Only whitelisted actions can be invoked.

§Example

ⓘ
let client = AnkiConnectClient::new(8765, Some("my-api-key"));

// List all deck names
let decks = client.deck_names().await?;

// Get live due count
let due = client.get_due_cards("Spanish::Vocab").await?;

pub fn new(port: u16, api_key: Option<String>) -> Self

Construct a new client targeting localhost:{port}.

If api_key is provided it is appended as ?key={api_key} to every request, matching AnkiConnect’s optional authentication mechanism.

Return deck statistics for one or more named decks.

pub async fn get_due_cards( &self, deck: &str, ) -> Result<Vec<i64>, AnkiConnectError>

Return IDs of all cards due in a named deck.

Uses findCards with an is:due filter scoped to the deck. This reflects the live scheduler queue — available only when Anki is running. Cards in states: new (type=0), learning (type=1), review (type=2, due <= now), relearning.

pub async fn sync(&self) -> Result<Value, AnkiConnectError>

Trigger a full Anki Web sync.

Requires Anki to have sync auth configured (ankiweb.net account or self-hosted sync server). This is the only safe way to synchronize the collection — doing it via direct SQLite writes would corrupt the sync log.

pub async fn suspend_cards( &self, cards: Vec<i64>, ) -> Result<bool, AnkiConnectError>

Suspend one or more cards by ID.

Suspended cards are excluded from reviews until unsuspended. The operation goes through Anki’s scheduler so card state is preserved.

pub async fn set_due_date( &self, cards: Vec<i64>, days: &str, ) -> Result<bool, AnkiConnectError>

Reschedule one or more cards to be due in N days.

days is a string: "0" = today, "1" = tomorrow, "7" = in a week. Negative values are supported ("-1" = yesterday).

pub async fn export_package( &self, deck: &str, path: &str, include_sched: bool, ) -> Result<bool, AnkiConnectError>

Export a named deck to an .apkg file on disk.

include_sched controls whether review history and scheduling data are included. Set to true for full backups, false for content- only exports.

Source

pub async fn import_package( &self, path: &str, deck: &str, ) -> Result<bool, AnkiConnectError>

Import an .apkg file into the collection.

Anki handles schema migration, notetype resolution, and scheduling reset. This is the only safe import path.

Source

pub async fn create_backup( &self, deck: &str, dir: &str, ) -> Result<String, AnkiConnectError>

Create a timestamped .apkg backup of a deck via exportPackage.

AnkiConnect has no native “backup” action — exportPackage with includeSched: true is the safe equivalent: it produces a portable .apkg with full scheduling history. The caller provides the deck name and a directory path; the file is named with a timestamp.
