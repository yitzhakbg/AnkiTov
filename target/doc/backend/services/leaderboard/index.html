Module leaderboard

Expand description

Leaderboard scoring service — one rule, every surface.

Implements specs/2026-10-06-leaderboard.md §5–§6. The class display, the student view, and the staff console all call rank, so a given student shows the same number everywhere and a rank is always explainable from the returned Inputs.

Pure and dependency-light: no DB, no HTTP. Callers aggregate capsule_sessions per student into StudentAggregate and hand the cohort in. This keeps the ranking rules unit-testable in isolation.
